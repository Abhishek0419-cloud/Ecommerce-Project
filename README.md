# 🛒 E-Commerce Sales Analysis using SQL & Python

## 📌 Project Overview

This project focuses on analyzing an e-commerce dataset using **MySQL and Python** to extract meaningful business insights from customer, order, product, payment, seller, and geolocation data.

The project demonstrates how SQL can be used to perform **data extraction, transformation, aggregation, and advanced analytical analysis** on relational e-commerce data.

Python was used alongside MySQL to load the datasets, execute SQL queries, convert query results into Pandas DataFrames, and create visualizations where required.

## 📊 Advanced SQL Examples

### Seller Ranking

```sql
SELECT *,
       DENSE_RANK() OVER(ORDER BY revenue DESC) AS seller_rank
FROM (
    SELECT 
        seller_id,
        ROUND(SUM(payment_value), 2) AS revenue
    FROM order_items
    JOIN payments
        ON order_items.order_id = payments.order_id
    GROUP BY seller_id
) AS seller_revenue;
```

### Moving Average

```sql
AVG(payment) OVER (
    PARTITION BY customer_id
    ORDER BY order_purchase_timestamp
    ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
)
```

### Cumulative Revenue

```sql
SUM(payment) OVER(
    ORDER BY years, months
) AS cumulative_revenue
```

### Top 3 Customers Per Year

```sql
DENSE_RANK() OVER(
    PARTITION BY YEAR(order_purchase_timestamp)
    ORDER BY SUM(payment_value) DESC
)
```
